# Хот тохижилтын ERP шаардлага ба roadmap

## Товч зорилго

Одоогийн аппыг гурван үндсэн үйл ажиллагааны хэлтэст ашиглахад бэлэн хот тохижилтын ERP болгоно. Бүх үндсэн хэлтэс `Ажил / Даалгавар / Тайлан` гэсэн нэгдсэн урсгалаар ажлаа төлөвлөж, ажилтанд оноож, mobile/PWA-аар гүйцэтгэл оруулж, мастер/менежерээр хянуулж, тайлан гаргана.

V1-ийн гол зорилго нь шинэ том боломж нэмэхээс илүү одоогийн аппыг production-ready болгох явдал.

## Албан хамрах хүрээ

### Үндсэн хэлтэс

- `Авто бааз, хог тээвэрлэлт`
- `Ногоон байгууламж, тохижилт үйлчилгээ`
- `Зам цэвэрлэгээ`

### Дэмжих хэлтэс

- `Хүний нөөц`: ажилтны бүртгэл, чөлөө, өвчтэй, томилолт, сахилга, тушаал/гэрээ, ажлаас гаралт, HR тайлан.
- `Санхүү`: V1-д зөвхөн худалдан авалтын төлбөр бүртгэл болон худалдан авалттай холбоотой тайлан.

### Нэгдсэн үндсэн урсгал

`Ажил / Даалгавар / Тайлан` нь хэлтсийн ажил төлөвлөх, даалгавар оноох, ажилтан гүйцэтгэлийн тайлан оруулах, мастер/менежер хянах, явц тооцох, Word/PDF тайлан гаргах үндсэн суурь урсгал байна.

### Хамрахгүй зүйл

- `Иргэдийн санал гомдол`
- Бүрэн accounting буюу санхүүгийн үндсэн бүртгэлийн модуль
- Худалдан авалтын хүлээн авалт, сэлбэг/материал ашиглалтаас цааших бүрэн warehouse/inventory модуль
- Нийтийн порталын нэмэлт боломжууд

## Бүтээгдэхүүний шаардлага

### Ажил / Даалгавар / Тайлан

- Хэлтсийн ажил/project үүсгэж, даалгавар онооно.
- Даалгаврын төлөв, явц, огноо, хариуцагч, хэлтэс, ажлын төрөл, нотлох баримтыг хадгална.
- Талбарын болон mobile хэрэглэгч тайлбар, тоо хэмжээ, зурагтай гүйцэтгэлийн тайлан илгээнэ.
- Мастер/менежер тайланг хянаж, батлах, буцаах, эцэслэх боломжтой байна.
- Төлөвлөсөн хэсгүүдэд Word/PDF тайлан export дэмжинэ.

### Авто бааз, хог тээвэрлэлт

- Машин техник, техник төрөл, жолооч оноолт, даатгал, улсын үзлэг, засварын түүх бүртгэнэ.
- Хог тээврийн маршрут төлөвлөх, өнөөдрийн маршрут үүсгэх, жолооч/ачигч гүйцэтгэх, зураг хавсаргах, цэг алгасах шалтгаан оруулах, хяналтын workflow дэмжинэ.
- Хогны машины жин/шатахууны мэдээллийг зөвхөн `.env` тохиргоонд суурилан татна.
- Засварын сэлбэг/үйлчилгээний үед худалдан авалтын урсгалтай холбоно.

### Ногоон байгууламж, тохижилт үйлчилгээ

- Нэгдсэн ажил/даалгавар/тайлангийн урсгалаар хэлтсийн ажлыг удирдана.
- Ажилтан оноох, mobile тайлан илгээх, мастер/менежер хянах, dashboard/report дээр тусгах боломжтой байна.
- Ногоон байгууламж болон тохижилт үйлчилгээний ажлын төрлүүдийг ялгаж бүртгэнэ.

### Зам цэвэрлэгээ

- Цэвэрлэх талбай бүртгэнэ.
- Өнөөдрийн цэвэрлэгээний ажил үүсгэнэ.
- Оноогдсон ажилтан mobile/PWA-аар өмнөх/дараах зураг, тайлбар, гүйцэтгэл илгээнэ.
- Мастер ажил хянаж батлах эсвэл шалтгаантай буцаана.
- Боломжтой хэсэгт нэгдсэн ажил/даалгавар/тайлангийн харагдацтай холбоно.

### Худалдан авалт

- Даалгавартай холбоотой худалдан авалтын хүсэлт үүсгэнэ.
- Хэлтсийн дарга хэрэгцээ оруулж, бараа/үйлчилгээний мөр, үнийн санал, нийлүүлэгчийн харьцуулалт бүртгэнэ.
- V1-д санхүү зөвхөн төлбөр бүртгэнэ.
- V1-д нярав/худалдан авалт зөвхөн хүлээн авалт болон сэлбэг/материал ашиглалтыг бүртгэнэ.
- 1,000,000 MNT-ээс дээш өндөр дүнгийн урсгалд одоогийн шаардлагын дагуу CEO/admin/legal гэрээний draft оролцоно.

### Хүний нөөц

- Ажилтны бүртгэл, profile, хавсралт, гэрээ, тушаал хадгална.
- Чөлөө, өвчтэй, томилолт, шилжилт хөдөлгөөн, сахилга, ажилтны тайлбар, ажлаас гаралт, тойрох хуудас, архив дэмжинэ.
- HR scope-д ирц, хоцролт, таслалт, attendance KPI, attendance report орохгүй.

### Самбар / Тайлан / Мэдэгдэл

- Менежер, HR, санхүү/худалдан авалт, авто бааз/засвар, хог тээвэр, зам цэвэрлэгээний dashboard байна.
- Оноогдсон ажил, буцаагдсан тайлан, худалдан авалтын шат, HR event, засварын workflow дээр push/Odoo activity мэдэгдэл дэмжинэ.
- Тайлангууд ажил гүйцэтгэл, хугацаа хэтэрсэн ажил, хяналт хүлээж буй ажил, худалдан авалтын төлбөр/хүлээн авалт, HR summary, техник/маршрутын төлөвийг харуулна.

### Төслийн бэлэн байдлын tracker

- Дэлгэцийн бүх label, товч, status, тайлбар Монгол хэлээр байна.
- Модуль бүрийн функц, дүрийн үйлдэл, workflow, testing completion-ийг автоматаар scan хийж харуулна.
- `100%` нь backend, frontend, эрх, integration, role action, validation, dashboard/report, testing evidence бүгд бүрэн үед л бүрэн гэж тооцогдоно.

## Замын зураг

### Үе шат 1: Одоогийн аппыг ашиглахад бэлэн болгох

- Гурван үндсэн хэлтэст `Ажил / Даалгавар / Тайлан` урсгалыг тогтворжуулна.
- Role access, menu, task/report permission, mobile screen, review action, export-ийг шалгана.
- Худалдан авалтын V1-ийг ашиглахад бэлэн болгоно: request, quote, payment record, receiving/parts usage, report.
- Авто бааз/засвар болон хог тээврийн route урсгалыг ашиглахад бэлэн болгоно.
- Зам цэвэрлэгээний MVP-г ашиглахад бэлэн болгоно.
- Testing workflow completion-тэй төслийн tracker нэмнэ.

### Үе шат 2: Хэлтсийн тогтвортой ажиллагаа

- Үндсэн хэлтэс бүрийн dashboard сайжруулна.
- Хэлтэс, дүр, огноо, төлөв, хугацаа хэтэрсэн ажлаар тайланг өргөжүүлнэ.
- Validation, record rule, буцаах шалтгаан, давхардал хориглох, audit trail-ийг чангаруулна.
- Дүр тус бүрийн ажлын урсгалын тест болон чанарын шалгалтын script-ийг өргөжүүлнэ.

### Үе шат 3: Үйл ажиллагааны сайжруулалт

- Талбарын ажилтны mobile UX сайжруулна.
- Мэдэгдлийн урсгалыг найдвартай болгоно.
- Засвар/худалдан авалтын холбоосыг бүрэн болгоно.
- Машин техникийн зардал, ашиглалт, гүйцэтгэлийн тайланг өргөжүүлнэ.
- Dashboard/KPI-г шаардлагатай хэмжээнд нарийвчилна.

### Ирээдүйн үе шат

- Бүрэн accounting integration
- Бүрэн inventory/warehouse модуль
- Зөвхөн дахин scope-д оруулбал public complaint/citizen portal
- Route optimization, GPS, offline queue, scoring зэрэг advanced боломжууд

## Бэлэн байдлын шалгуур

Модуль production-ready гэж тооцогдохын тулд:

- Backend model болон field байна.
- Security group, access, record rule байна.
- Шаардлагатай Odoo menu, view, action байна.
- Next.js page/API integration байна.
- Холбогдох бүх дүрийн үйлдэл ажиллана.
- Workflow state болон validation backend/frontend түвшинд мөрдөгдөнө.
- Dashboard/report coverage байна.
- Testing workflow дууссан, нотолгоотой байна.

## Суурь assumption

- V1 санхүүгийн scope нь зөвхөн худалдан авалтын төлбөр болон худалдан авалтын тайлан.
- V1 warehouse scope нь зөвхөн худалдан авалтын хүлээн авалт болон сэлбэг/материал ашиглалт.
- Одоогийн аппыг production-ready болгох нь шинэ том feature нэмэхээс түрүүнд тавигдана.
- `Иргэдийн санал гомдол` нь албан scope-оос хасагдсан.
